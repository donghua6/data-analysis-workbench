# 数据分析工作台使用手册

## 1.界面介绍

数据分析工作台用于查看机器人关节状态与目标动作，通过三路相机和关节曲线的同步回放，检查录制数据的动作过程与跟踪误差。

支持 LeRobot 数据集、CSV / JSON、ROS1 bag 和 ROS2 db3 / MCAP 采集目录。已适配天机臂、FR3、UR 机械臂及 Sharpa、Wuji 灵巧手的相关数据格式。

界面分为四个区域：

- 关节选择区：位于左侧，按左臂、右臂、左手、右手选择关节。
- 数据概览区：显示当前数据集、episode、时长、关节数量及数据点数。
- 相机回放区：显示当前 episode 的三路画面，提供播放、暂停、倍速和进度控制。
- 关节分析区：显示所选关节的 State / Action 曲线、时间游标及误差指标。

导入完成后默认不选择关节。勾选关节后显示对应图表；未勾选时图表区为空，相机仍可独立回放。



## 2.导入数据

### 2.1 打开工作台

在部署工作台的主机上，通过浏览器访问 http://127.0.0.1:8877/ 。服务未运行时，进入项目目录执行：

```bash
./start_analysis.sh
```

保持服务进程运行。8877 为数据分析工作台端口，8765 为数据清洗工作流端口。两套服务独立启动。

远程数据应先挂载至运行工作台的主机，并确认目录可正常读取。导入窗口填写该主机可访问的绝对路径。

### 2.2 选择数据目录

LeRobot 数据集通常包含以下结构：

```text
数据集目录/
  meta/info.json
  meta/episodes.jsonl
  data/chunk-000/episode_000000.parquet
  data/chunk-000/episode_000001.parquet
  videos/chunk-000/相机名称/episode_000000.mp4
```

支持一个目录包含多条 episode，也支持扫描包含多个数据集的上级目录。大数据集优先使用目录路径导入；每次读取所选 episode 的关节数据，视频按需加载，不上传整个数据集。

### 2.3 从界面导入

1. 点击右上角“导入数据”，或按 I 键。
2. 在“直接读取采集目录 / LeRobot”中填写数据目录绝对路径。
3. 点击“扫描目录”，等待录制列表加载。
4. 在“选择录制”中选择 episode，确认帧数、fps 和相机数量。
5. 点击“导入关节数据 →”。
6. 导入成功后，核对主界面数据名称与统计信息，再选择需要查看的关节。

扫描上级目录时，选项包含相对目录。选择时应区分设备类型、A/B 组、normal / speedup、历史版及测试版，避免仅凭 episode 编号选择录制。



## 3.切换录制与选择关节

### 3.1 切换 episode

通过数据名称下方的下拉框切换 episode。切换成功后，关节数据、统计信息、相机视频和时间轴同步更新。关节选择重新置空，需重新勾选。

刷新页面后，工作台尝试恢复上次成功导入的路径与 episode。共享目录不可读时无法恢复。切换失败时保留上次成功加载的数据，应根据错误提示处理后重新选择。

### 3.2 选择关节

- “全部关节”：勾选并显示全部关节；再次点击取消全部勾选。
- 臂 / 手分组：整组勾选或取消，支持跨分组选择。
- 关节复选框：单独勾选或取消对应关节。
- 搜索框：按名称筛选已选关节，不自动选中未勾选关节。
- “每页显示”：设置显示数量；展开按钮显示其余已选关节。

取消全部勾选后不显示关节图。排查具体动作时，可选择相关关节缩小查看范围。

## 4.相机回放与时间同步

### 4.1 播放与定位

三路相机使用统一播放控制。相机名称依据数据集配置显示，如 cam0 / cam1 / cam2 或 head / left_wrist / right_wrist。

- 播放 / 暂停：同时控制三路视频。
- 倍速：支持 0.5×、1×、2×。
- 进度条：拖动相机下方进度条，同步定位视频和关节图游标。
- 竖向虚线：在任意关节图内按住并左右拖动，同步调整所有关节游标、三路视频及进度条。
- 展开画面：放大相机区域，再次点击收起。

拖动进度条或图表虚线时暂停播放，松手后停在所选帧。继续播放需点击“播放”。普通鼠标悬停不改变视频时间。

### 4.2 时间基准

相机、进度条与关节图共用 LeRobot 逐帧 timestamp。跳转和暂停吸附到对应数据帧，页面显示当前帧编号；数据包含 source_timestamp_ns 时，同时显示源时间。

10 fps 数据的帧间隔约为 0.1 秒，30 fps 约为 0.033 秒。同步回放不改写原始采集时间，也不代表不同传感器的原始曝光时刻完全相同。

当前界面通过相机进度条统一定位。关节图展示整条 episode；移动游标不裁剪数据，也不改变整条录制的误差统计范围。



## 5.关节曲线与误差分析

### 5.1 State / Action

绿色实线为 State，表示实际状态；紫色虚线为 Action，表示目标动作。可分别隐藏曲线，隐藏操作不改变误差计算。

系统按关节名称匹配位置维度，支持 .position / .command 混合命名及 State 包含额外速度维度的情况。位置分析提取可识别的位置数据。名称、维度或物理含义无法对应时，应核对数据定义，不应直接通过索引匹配绕过检查。

部分录制仅包含机械臂 Action。此时保留灵巧手 State 曲线，Action 为空，不生成缺失目标值。页面摘要显示可对比关节和仅 State 关节数量。

### 5.2 指标含义

- MAE：有效配对样本的平均绝对误差。
- MAX：有效配对样本的最大绝对误差。
- 配对数：参与计算的 State / Action 样本数量。
- 误差容差：默认 30 ms，以 State 采样时间查找容差内最近的 Action 样本，不做插值。
- “—”：无有效配对数据，不表示误差为零。

游标读数对应当前时刻，MAE / MAX 对应整条 episode 的有效配对样本。图表按各关节数值范围独立缩放，不应仅凭曲线起伏高度比较不同关节的误差。

### 5.3 单位

导入单位应与源数据一致。rad → ° 仅转换标记为 rad 的关节显示，导出保留原始单位。速度、力矩及归一化动作不得直接作为位置误差计算输入。

## 6.数据目录

以下为已适配的数据入口。路径需结合实际共享挂载位置使用。

- tang-zhe：data-demo/real/wujing/data/lerobot/sharpa/tang-zhe/；支持双臂与双手共 58 个位置关节。
- stick：data-fruits/real/tool_grasping/data/stick/data_lerobot_v2.1/A/1103_12_153_data_lerobot/；74 条 episode，58 个关节。
- scoop-lemon：data-fruits/real/scoop-lemon/；current 版 433 条，两套历史版分别 224 / 367 条；52 个状态关节，其中双臂 12 个可对比、双手 40 个仅 State，视频为 10 fps。
- harvest-tomato：data-fruits/real/harvest-tomato/data/；36 套数据集、3630 条 episode 索引，包含 Sharpa、Wuji、normal / speedup 及历史版；Sharpa 为 58 个位置关节，Wuji 为 54 个。

本机共享挂载前缀示例：/home/user/company-remote-202/。将挂载前缀与上述相对目录组合，填写至导入窗口。

数量为 2026-11-05 扫描记录，包含不同版本及历史副本，不代表去重后的独立采集数量。适配验证覆盖代表性录制，不等于全部 episode 已通过数据质量检查。

## 7.数据格式与导出

### 7.1 其他格式

CSV / JSON 支持文件选择和拖拽导入。CSV 使用 time、joint、state、action、unit 长表，可通过“CSV 模板”下载示例。JSON 需要非空 joints 数组。

ROS 支持 ROS1 .bag 和带完整 metadata.yaml 的 ROS2 db3 / MCAP 目录。标准采集目录可自动配对同一命名空间的 joint_states 与 command 等 Topic；其他录制通过“字段与 Topic 配置”手动指定。

ROS 默认使用 bag 记录时间。仅在显式启用支持的 alignment 裁剪时，使用相应 header.stamp 源时间。

### 7.2 导出范围

选择关节后点击“导出”，下载 JSON，可再次导入。导出当前已选且符合搜索条件的关节，范围为整条 episode，不包含视频。移动时间游标不改变导出范围。

### 7.3 使用限制

文件上传上限 512 MB，解析上限 200 万标量点。大文件使用本地目录路径。上传 LeRobot 文件或文件夹只导入关节；相机回放使用路径导入。

Rerun 为独立的 RRD 回放入口，当前不提供与工作台联动的三维模型时间轴。

## 8.常见问题

导入成功但无图表：检查左侧关节勾选状态及搜索条件。未勾选关节时图表区为空。

连接失败 / Failed to fetch：检查 8877 服务进程，启动后刷新页面并重新扫描。服务已运行时不要重复启动。

Address already in use：端口已被占用。使用已有服务；更新后端代码时先停止旧进程，再启动新服务。

Input/output error / Errno 5：检查共享目录读取状态。文件管理器也无法访问时，先恢复内网 / VPN 连接或重新挂载，再扫描和导入。该错误本身不能说明数据文件损坏。

名称或维度不匹配：确认 meta/info.json 与 Parquet 属于同一数据集，核对 State / Action 列名、关节定义及单位。

MAE / MAX 为“—”：检查 Action 是否存在，以及匹配容差内是否有有效配对。仅 State 关节不计算误差。

视频加载失败：检查同一 episode 的视频文件、共享目录连接和浏览器编码支持。

切换失败后仍显示旧画面：显示内容为上次成功加载的录制。处理错误后重新选择，并核对数据名称。

问题排查时记录完整数据集路径、episode 编号、错误提示和对应时间点，便于复现定位。
